<p>Cada función devuelve de inmediato una instancia de efecto (<code>EffectHandle</code>). Consérvala para controlar la animación, comprobar el resultado de la configuración y liberar recursos. <a href="/docs/es/api/shared#control-playback">Tiempo e intensidad</a> son sus controles modificables. Cada instancia tipada salvo Burned paper extiende <code>ColorEffectHandle</code>: su propiedad <code>color</code> devuelve <code>rgb(...)</code> normalizado o <code>undefined</code> para los colores originales del efecto. Frost también expone <code>mistOpacity</code>, Burned paper expone <code>emberGlow</code> y Fire expone su valor de creación resuelto <code>emberDensity</code>.</p>

## Comprende el estado informado

<p><code>lifecycle</code> indica si el efecto puede dibujarse. <code>raster</code> indica si la imagen capturada está actualizada. <code>paused</code> solo indica si la animación automática de domfx está pausada. Estos valores describen aspectos distintos.</p>

<p>Un efecto controlado por GSAP tiene <code>paused: true</code> mientras cambia su tiempo. Un efecto puede tener <code>paused: false</code> aunque temporalmente no pueda dibujarse. Un efecto inmóvil puede estar activo, actualizado y visible.</p>

<p>Espera a <code>ready</code> para el intento de configuración inicial, a <code>refresh()</code> para actualizar la captura o a <code>retry()</code> para un nuevo intento de configuración después de corregir un problema. El reintento conserva la promesa <code>ready</code> original. Ninguna de estas promesas indica que terminó la animación, la ejecución en la GPU o la presentación en pantalla; consulta el estado para saber si está disponible.</p>
