<p>Un tween de GSAP es un objeto de animación que cambia propiedades con el tiempo. Usa estas animaciones nativas con cualquier efecto de domfx y una línea de tiempo para ordenarlas. La instancia permite modificar las propiedades numéricas <code>time</code> e <code>intensity</code>. No necesitas registrar un plugin de domfx ni importar <code>@domfx/gsap</code>.</p>

<p>Sigue la <a href="/docs/es/installation#add-the-optional-gsap-binding">guía de instalación</a> y añade GSAP a tu aplicación. Este ejemplo usa Fire; sustituye su importación y omite <code>flameHeight</code> para usar otro efecto.</p>

## Proporciona tus elementos

<p>Usa el <code>index.html</code> de <a href="/docs/es/installation#provide-the-target-and-host">instalación</a>, incluido el contador de clics. Sustituye todo el contenido de <code>main.ts</code> por el siguiente módulo. En un componente, ejecútalo después de montar los elementos.</p>

<span id="build-your-sequence" />

## Construye tu secuencia

<p>Crea el efecto con <code>clock: 'manual'</code> para que GSAP controle su tiempo. El contenedor aparece gradualmente en medio segundo; luego el efecto pasa del tiempo 0 al 4 y de intensidad 0.8 a 0.4 durante cuatro segundos. Anima la opacidad del contenedor para que el objetivo original y el efecto la compartan. Los cambios de opacidad solo en el objetivo no son compatibles.</p>

<span id="seek-and-play" />

## Avanza y reproduce

<p>Después de preparar el efecto, usa <code>timeline.play()</code>, <code>pause()</code>, <code>seek()</code> y <code>reverse()</code>. En <code>timeline.seek(2.5)</code>, el tiempo del efecto es 2 y la intensidad 0.6. Retroceder a 1.5 da tiempo 1 e intensidad 0.7. Los saltos a un punto de la línea de tiempo también actualizan estas propiedades, aunque no ejecuten las funciones de devolución de llamada (callbacks); no hace falta copiar sus valores en <code>onUpdate</code>.</p>

<p>Encadena llamadas a <code>.to()</code> para animar desde los destinos anteriores. Usa <code>.from()</code> o <code>.fromTo()</code> para indicar valores iniciales explícitos, teniendo en cuenta su renderizado inmediato predeterminado. Los segmentos <code>.fromTo()</code> posteriores suelen necesitar <code>immediateRender: false</code>. <code>ease</code> define cómo varía la velocidad de la animación. <code>ease</code>, <code>repeat</code>, <code>yoyo</code>, <code>overwrite</code> y <code>timeScale()</code> siguen las convenciones normales de GSAP.</p>

<p><code>gsap.killTweensOf(fire, 'intensity')</code> detiene solo esa propiedad; no libera el efecto ni detiene una animación de tiempo. Usa un controlador por propiedad y mantén los valores dentro de los <a href="/docs/es/api/shared#control-playback">rangos de control</a>.</p>

<span id="animate-color" />

## Anima el color

<p>Todos los efectos excepto Burned paper permiten modificar <code>color</code>. Inicialízalo con una cadena de color opaca explícita y admitida, y después usa extremos opacos explícitos con <code>fromTo()</code>; la paleta original es <code>undefined</code>, no un valor entre el que interpolar. Esto cambia la decoración y conserva el objetivo y la opacidad del efecto.</p>

```ts
fire.color = '#ff6600';
const colorTween = gsap.fromTo(
  fire,
  { color: '#ff6600' },
  { color: '#6699ff', duration: 2, ease: 'power1.inOut' },
);
```

<p>Para cambios posteriores, usa <code>{"gsap.to(fire, { color: '#ff6600', duration: 2 })"}</code>. Al limpiar, llama a <code>colorTween.kill()</code> antes de liberar el efecto. Para recuperar la paleta original, detén las animaciones de color y asigna <code>fire.color = undefined</code>.</p>

<span id="own-the-lifetime" />

## Gestiona el ciclo de vida

<p>Registra <code>cleanup()</code> en el mecanismo de desmontaje de tu framework antes de llamar a <code>setup()</code>. Elimina los controladores de eventos, revierte y elimina la línea de tiempo propia y libera el efecto. Funciona incluso si las fuentes o <code>ready</code> siguen pendientes. La suscripción de liberación también restaura la opacidad si se elimina el objetivo. Al volver a montar, crea variables, efecto y línea de tiempo nuevos.</p>

<p>Si usas una línea de tiempo ajena, conserva referencias a tus animaciones hijas y elimina solo esas animaciones con <code>kill()</code>; su propietario limpia la línea de tiempo y las demás animaciones. Terminar, eliminar o sobrescribir una animación no libera los recursos del objetivo.</p>

<span id="context-cleanup" />

<span id="gsap-context-cleanup" />

### Limpieza del contexto GSAP

<p>Crea las animaciones dentro de <code>gsap.context()</code> y devuelve una función de limpieza explícita. Regístrala de forma síncrona; el contexto no registra automáticamente el trabajo creado después en funciones que esperan promesas.</p>

<p>Si adaptas este ejemplo a un contexto, devuelve <code>cleanup</code> desde su función de configuración y llama a <code>context.revert()</code> al desmontar.</p>

<span id="optional-bindings" />

<span id="optional-lifecycle-helpers" />

## Funciones opcionales de ciclo de vida

<p><code>@domfx/gsap</code> proporciona <code>bindEffect</code> y <code>bindEffectAsync</code> para enlaces que conservan los valores iniciales de los controles, con responsabilidad explícita de limpieza. La función asíncrona libera con seguridad los resultados que llegan después de cancelar. Los nombres compatibles <code>bindFire</code> siguen disponibles para todos los efectos.</p>

<p>Estas funciones capturan los controles iniciales al crearse y animan objetivos proxy privados. Difieren de las llamadas nativas encadenadas a <code>.to()</code>, de la eliminación de animaciones por objetivo con <code>gsap.killTweensOf()</code> y de la sobrescritura. Consulta la <a href="/docs/es/api/gsap#snapshot-bindings">referencia de enlaces con valores iniciales fijos</a> si necesitas ese contrato; para secuencias normales, prefiere animaciones nativas.</p>

<span id="unavailable-and-retry" />

<span id="unavailable-output-and-retry" />

## Salida no disponible y reintento

<p>El ejemplo principal inicia la reproducción solo cuando el efecto está activo. Si WebGPU no está disponible o se solicita movimiento reducido, conserva el objetivo original. Corrige la condición, espera a <code>fire.retry()</code>, consulta su estado y reproduce la línea de tiempo existente. El reintento conserva los controles; no necesita otra animación.</p>

<p>Cada <a href="/docs/es/api/effects">referencia de efecto</a> comienza con una vista previa interactiva de los controles compartidos. Consulta la <a href="/docs/es/api/gsap">API de GSAP</a> y <a href="/docs/es/troubleshooting">solución de problemas</a> para más detalles.</p>
