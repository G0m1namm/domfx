# Dependency advisory review (2026-10-18)

## Scope and decision

At `eb97f5d3f8726de66b9c77946c3e0272e7970ef9`, `pnpm audit --json` reported one critical, three high, and one moderate finding. The website uses Astro's `output: 'static'`; its image cache, TOML parser, and image service run during development or build, rather than in the deployed static pages. Vite and its source-map consumers run in the build/development toolchain. The Changesets editor is a contributor CLI. None of these paths enters the browser library bundle. These classifications describe this repository's current invocation, not a guarantee for another deployment that accepts untrusted inputs.

Keep Astro 7.3.3, Vite, pnpm 11.5.0, Oxfmt, Oxlint, and the `@typegpu/sdf` patch pinned as before. Use the existing compatible transitive ranges and one lockfile deduplication for the five findings. The overrides in `pnpm-workspace.yaml` preserve the selected versions on future installs; remove each when its owner reliably resolves a safe version without an override.
