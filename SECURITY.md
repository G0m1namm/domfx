# Security

domfx is experimental and has no supported stable releases yet. Reports against
`0.1.0-alpha.0` and the current `main` branch are welcome; no response-time guarantee is offered.

Email [coste200910@gmail.com](mailto:coste200910@gmail.com) privately with the
affected commit, impact and minimal reproduction. Do not post vulnerabilities,
credentials or private user data in public issues or pull requests.

The maintainer will assess the report and coordinate a fix and disclosure with
the reporter. Use [GitHub private vulnerability reporting](https://github.com/G0m1namm/domfx/security/advisories/new)
or email. Both channels are available.
