## Controla la animación

<p>Usa <code>clock: 'auto'</code> para la animación automática. domfx avanza el tiempo mientras puede dibujar el efecto, sin recuperar el tiempo pasado en pausa, oculto o fuera de pantalla. <code>'ambient'</code> es la forma anterior del mismo comportamiento y sigue admitida. La propiedad de solo lectura <code>clock</code> conserva el valor que proporcionaste.</p>

<p>Usa <code>clock: 'manual'</code> para el control externo mediante tu código o GSAP. domfx nunca avanza el tiempo en este modo, ni siquiera después de <code>resume()</code>. Sigue programando el renderizado y observando el objetivo; el control manual no implica renderizado inmediato.</p>

<p><code>time</code> elige un punto de la animación en segundos. No es un progreso de 0 a 1 ni el tiempo real transcurrido. Puedes retroceder o asignar valores negativos. Deja cada propiedad modificable a cargo de un único controlador de animación.</p>

<span id="reduced-motion" />

## Movimiento reducido

<p>El valor predeterminado <code>motion: 'respect'</code> suprime la salida cuando la persona solicita movimiento reducido. Cuando la preferencia vuelva a cambiar, llama explícitamente a <code>retry()</code>. No sustituye automáticamente la animación por un fotograma inmóvil.</p>

<p><code>motion: 'static'</code> siempre dibuja un efecto inmóvil en el tiempo cero, con cualquier preferencia. Los cambios de tiempo siguen siendo legibles, pero no alteran el fotograma dibujado. La intensidad y las actualizaciones de captura siguen funcionando. <code>resume()</code> no lo anima.</p>

<p>Consulta <a href="/docs/es/api/effect-handle">estado y métodos del efecto</a> para preparación, pausa, reanudación, actualización de captura, reintento y limpieza.</p>
