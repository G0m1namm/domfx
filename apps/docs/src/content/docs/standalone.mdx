## Use another effect

<p>Replace <code>attachFire</code> with an attachment such as <code>attachFrost</code> or <code>attachDither</code> and remove <code>flameHeight</code>. The remaining options and handle methods are shared. Intensity changes each effect's appearance; it is not a universal height or opacity setting.</p>

<p>Dispose the existing attachment before attaching another effect to the same target. Every <a href="/docs/api/effects">effect reference</a> opens with the same live preview, and the <a href="/effects/">gallery</a> compares them side by side.</p>

## Control time and intensity

<p><code>fire.pause()</code> pauses automatic animation. <code>fire.resume()</code> continues without catching up time spent paused or hidden. Set <code>fire.intensity</code> to a value between 0 and 1. See the <a href="/docs/api/shared#control-playback">control reference</a> for accepted values.</p>

<p>For explicit seeking, choose <code>clock: 'manual'</code> at creation and write <code>fire.time</code> in absolute seconds. Forward and backward seeks reuse the capture. With external control, <code>paused</code> stays true even while time changes; <code>resume()</code> does not advance it.</p>

## Refresh and cleanup

<p>After changing captured paint, await <code>fire.refresh()</code>. It hides stale output and resolves once this or a newer requested capture is accepted. Observed target mutations and resize can refresh automatically; unobserved stylesheet, hover or ancestor paint changes still need explicit refresh.</p>

<p>Refreshing recaptures the target's appearance without bypassing image caching. For changing image content, use versioned URLs or server cache headers that require revalidation.</p>

<p>Call <code>cleanup()</code> on component unmount; <code>pagehide</code> only covers leaving the page. It is safe to call more than once, including while fonts or <code>ready</code> are pending. Register it synchronously in your framework’s teardown hook before calling <code>setup()</code>. On remount, run the module’s setup and ownership code again with fresh variables and elements; a disposed effect cannot be reused.</p>

## Unavailable output

<p><code>ready</code> resolves after an attempt, including environmental unavailability. Inspect <code>fire.lifecycle</code>, <code>fire.raster</code> and <code>fire.reason</code>. Keep the original content available. After correcting the condition, explicitly await <code>fire.retry()</code> and inspect the result again.</p>

<p>The default <code>motion: 'respect'</code> suppresses output under reduced motion. Changing the preference back requires an explicit retry. <code>motion: 'static'</code> opts into a still decoration at time zero; it never overrides reduced motion with animation.</p>
