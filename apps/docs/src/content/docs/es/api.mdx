<p>Los {effects.length} efectos aceptan opciones de creación compartidas y devuelven una instancia (<code>EffectHandle</code>). Comienza por la referencia de un efecto para conocer su importación, aspecto y opciones compatibles.</p>

<span id="usage" />

## Uso

<p>Importa una función de efecto desde <code>@domfx/browser</code>. Llámala en el navegador después de montar el elemento objetivo y el contenedor del efecto (<code>host</code>). El contenedor debe contener el objetivo y tener una posición CSS distinta de <code>static</code>. Puedes importar el paquete durante el renderizado en el servidor (SSR); aplicar efectos y capturar su apariencia requieren elementos del DOM en el navegador.</p>

<div class="docs-code-scroll" tabindex="0" role="region" aria-label="Ejemplo de opciones compartidas de efecto"><Code code={`import { attachFrost } from '@domfx/browser';
import type { AttachmentOptions } from '@domfx/browser';

const options: AttachmentOptions = {
host,
clock: 'manual',
intensity: 0.8,
};
const effect = attachFrost(target, options);

// Libera también el efecto al desmontar el componente.
window.addEventListener('pagehide', () => effect.dispose(), { once: true });
await effect.ready;
if (effect.lifecycle === 'active') {
effect.time = 2;
}`} lang="ts" theme={codeTheme} /></div>

<p>Cada función recibe <code>(target: Element, options)</code> y devuelve de inmediato un <code>EffectHandle</code>. Consulta la <a href="/docs/es/standalone">guía de uso independiente</a> para una configuración completa.</p>

### Opciones específicas del efecto

<p><a href="/docs/es/api/effects/fire#effect-options"><code>flameHeight</code> de Fire</a> es actualmente la única opción de creación adicional.</p>

<span id="control-playback" />

<span id="writable-controls" />

## Controles modificables

<p>Asigna <a href="/docs/es/api/shared#control-playback">tiempo e intensidad</a> directamente o mediante GSAP. El tiempo se mide en segundos; la intensidad varía entre 0 y 1 y cambia el aspecto de cada efecto.</p>

<span id="read-only-state" />

## Estado de solo lectura

## GSAP

<p>Usa <code>gsap.to()</code> y llamadas normales de línea de tiempo sobre una instancia de efecto. La <a href="/docs/es/api/gsap">referencia de GSAP</a> explica los enlaces opcionales que conservan valores iniciales fijos y gestionan la limpieza.</p>
