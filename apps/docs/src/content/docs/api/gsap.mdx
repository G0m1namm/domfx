## Native property tweens

<p>A tween animates property values over time. Use <code>{'gsap.to(effect, { time, intensity, duration, ease })'}</code> or add the same target to a timeline. Use <code>clock: 'manual'</code> when creating the effect. No domfx plugin registration or <code>@domfx/gsap</code> import is needed for these numeric properties.</p>

<p>GSAP writes the effect's public setters, including during callback-suppressed seeks. Chained <code>.to()</code> calls start from the preceding values. <code>.from()</code>, <code>.fromTo()</code>, <code>ease</code> (the rate of change), repeat/yoyo, property overwrite and <code>gsap.killTweensOf(effect)</code> use standard GSAP behavior.</p>

<p>Keep values within the <a href="/docs/api/shared#control-playback">effect control ranges</a>. The instance validates writes at runtime; GSAP's types do not enforce these ranges. <code>intensity</code> clamps per write, so overshooting eases may clip its animation.</p>

<p>Kill your tweens and dispose your effect during teardown. Killing or completing a tween does not dispose its target. Register cleanup immediately, including when setup is still pending. See the <a href="/docs/gsap">complete GSAP guide</a> for the lifecycle pattern.</p>

<span id="snapshot-bindings" />

## Optional snapshot bindings

<p>Choose a binding when you need fixed starting values or its cleanup helpers. For ordinary sequences, use the native tweens above.</p>
