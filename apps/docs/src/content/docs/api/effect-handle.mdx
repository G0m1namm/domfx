<p>An effect instance (<code>EffectHandle</code>) is returned immediately by every effect function. Keep it to control animation, check setup results and release resources. <a href="/docs/api/shared#control-playback">Time and intensity</a> are its writable controls. The Frost, Slime and Burned paper typed handles also expose <code>mistOpacity</code>, <code>gloss</code> and <code>emberGlow</code>; Fire and Halftone typed handles expose their resolved creation-only <code>emberDensity</code> and <code>dotSpacing</code> as read-only.</p>

## Understand the reported state

<p><code>lifecycle</code> reports whether the effect can render. <code>raster</code> reports whether its captured image is up to date. <code>paused</code> reports only whether domfx's automatic animation is paused. These values describe different things.</p>

<p>A GSAP-controlled effect has <code>paused: true</code> while its time changes. An effect can have <code>paused: false</code> while temporarily unable to render. A still effect can be active, up to date and visible.</p>

<p>Await <code>ready</code> for the initial setup attempt, <code>refresh()</code> for an updated capture, or <code>retry()</code> for a new setup attempt after correcting a problem. Retry keeps the original <code>ready</code> promise. None of these promises signals animation completion or completed GPU execution/screen presentation; inspect state for availability.</p>
