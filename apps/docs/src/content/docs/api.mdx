<p>All {effects.length} effects accept shared creation options and return an effect instance (<code>EffectHandle</code>). Start with an effect's reference for its import, appearance and supported options.</p>

<span id="create-an-attachment" />

## Usage

<p>Import an attachment function from <code>@domfx/browser</code>. Call it after the target and its positioned host are mounted. Imports are SSR-safe; attachment and capture require browser DOM elements.</p>

<div class="docs-code-scroll" tabindex="0" role="region" aria-label="Shared attachment options example"><Code code={`import { attachFrost } from '@domfx/browser';
import type { AttachmentOptions } from '@domfx/browser';

const options: AttachmentOptions = {
host,
clock: 'manual',
intensity: 0.8,
};
const effect = attachFrost(target, options);

// Also dispose on component unmount.
window.addEventListener('pagehide', () => effect.dispose(), { once: true });
await effect.ready;
if (effect.lifecycle === 'active') {
effect.time = 2;
}`} lang="ts" theme={codeTheme} /></div>

<p>Each attachment takes <code>(target: Element, options)</code> and immediately returns an <code>EffectHandle</code>. See the <a href="/docs/standalone">Standalone guide</a> for a complete setup.</p>

## Creation options

<p>Choose the target's container, animation control, reduced-motion behavior and initial values in the <a href="/docs/api/shared#attachment-options">shared options reference</a>.</p>

<span id="fire-only-options" />

### Effect-specific options

<p><a href="/docs/api/effects/fire#effect-options">Fire's flameHeight</a> is currently the only additional creation option. Each effect has its own reference so additional controls can be documented where they belong when supported.</p>

<span id="control-playback" />

## Writable controls

<p>Set <a href="/docs/api/shared#control-playback">time and intensity</a> directly or through GSAP. Time is in seconds; intensity is an effect-specific strength from 0 to 1.</p>

<span id="read-state" />

## Read-only state

<p>Inspect <a href="/docs/api/effect-handle#read-state">readiness, effect state and capture status</a>. A completed setup attempt does not guarantee visible output.</p>

<span id="refresh-retry-and-dispose" />

## Methods

<p><a href="/docs/api/effect-handle#refresh-retry-and-dispose">Pause, resume, refresh, retry and dispose</a> have the same contract for every effect.</p>
