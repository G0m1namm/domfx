<p>Los {effects.length} efectos aceptan opciones de creación compartidas y devuelven una instancia (<code>EffectHandle</code>). Comienza por la referencia de un efecto para conocer su importación, aspecto y opciones compatibles.</p>

<span id="usage" />

## Uso

<p>Importa una función de efecto desde <code>@domfx/browser</code>. Llámala después de montar el objetivo y su contenedor posicionado. Las importaciones son seguras durante SSR; adjuntar y capturar requieren elementos DOM del navegador.</p>

<div class="docs-code-scroll" tabindex="0" role="region" aria-label="Ejemplo de opciones compartidas de efecto"><Code code={`import { attachFrost } from '@domfx/browser';
import type { AttachmentOptions } from '@domfx/browser';

const options: AttachmentOptions = {
host,
clock: 'manual',
intensity: 0.8,
};
const effect = attachFrost(target, options);

// Also dispose on component unmount.
window.addEventListener('pagehide', () => effect.dispose(), { once: true });
await effect.ready;
if (effect.lifecycle === 'active') {
effect.time = 2;
}`} lang="ts" theme={codeTheme} /></div>

<p>Cada función recibe <code>(target: Element, options)</code> y devuelve de inmediato un <code>EffectHandle</code>. Consulta la <a href="/docs/es/standalone">guía de uso independiente</a> para una configuración completa.</p>

### Opciones específicas del efecto

<p><a href="/docs/es/api/effects/fire#effect-options"><code>flameHeight</code> de Fire</a> es actualmente la única opción de creación adicional. Cada efecto tiene su propia referencia para documentar sus controles adicionales cuando sean compatibles.</p>

<span id="control-playback" />

<span id="writable-controls" />

## Controles modificables

<p>Asigna <a href="/docs/es/api/shared#control-playback">tiempo e intensidad</a> directamente o mediante GSAP. El tiempo se mide en segundos; la intensidad es una fuerza específica del efecto entre 0 y 1.</p>

<span id="read-only-state" />

## Estado de solo lectura

<p>Consulta la <a href="/docs/es/api/effect-handle#read-state">preparación, el estado del efecto y el estado de captura</a>. Que termine la configuración no garantiza una salida visible.</p>

## GSAP

<p>Usa <code>gsap.to()</code> y llamadas normales de línea de tiempo sobre una instancia de efecto. La <a href="/docs/es/api/gsap">referencia de GSAP</a> también documenta los enlaces opcionales de instantánea y sus nombres compatibles.</p>
